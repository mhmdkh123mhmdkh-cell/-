# Mohammad's Opportunity Hub

Project Overview

Build a responsive, modern, Arabic-first personal website for Mohammad Al-Khayouti.

This is a one-page personal opportunity website, not a traditional CV, not a portfolio filled with links, and not a commercial services website.

The website should communicate, within a few seconds:

•
Who Mohammad Al-Khayouti is.

•
What he can do.

•
What practical experiences support those abilities.

•
That he is currently working on a personal idea called Tima Med Tours.

•
That he is explicitly looking for work Online or Offline in Damascus.

•
How the visitor can contact him immediately.

The website must present Mohammad through what he can do, not through exaggerated job titles or generic personal qualities.

Critical Execution Rules

•
Build the website directly. Do not create a separate planning page.

•
Use Arabic as the visible website language.

•
Use RTL layout throughout the website.

•
Use the exact Arabic copy provided in this prompt. Do not rewrite it, expand it, summarize it, or replace it with generic marketing copy.

•
Do not invent information, achievements, services, clients, credentials, testimonials, or work results.

•
Do not add sections that are not specified in this prompt.

•
Do not add a CV, timeline, blog, dynamic portfolio, login, database, dashboard, or user accounts.

•
Do not add a contact form that requires a backend. Use direct WhatsApp, LinkedIn, and email links.

•
Do not use words such as “expert”, “professional”, “specialist in everything”, “full-service”, “I create success”, or equivalent Arabic claims.

•
Do not describe Mohammad as offering project planning or project development services. Tima Med Tours is his own personal idea, not a service offered to other people.

•
Do not add stock photography unless absolutely necessary. Prefer custom SVG/CSS illustrations and a consistent line-art visual language.

•
Keep the page concise. Every section must have a clear visual and informational purpose.

Target Visitor

The visitor may be an employer, company owner, office manager, shop owner, startup founder, website or page owner, or project/team member looking for a capable person for a specific role or task.

The visitor should be able to decide for themselves whether Mohammad fits their need. The website should not force a single job title on him.

Build one polished scrolling page in this exact order:

2.

3.

4.

Experience evidence strip.

5.

6.

Short personal introduction.

7.

8.

Footer.

Do not add a navigation system with many pages. A simple sticky header with the name and anchor links is acceptable, but keep it minimal.

Visual Identity

Color palette

Use a restrained, warm, professional palette:

•
Deep navy or night blue as the primary dark color.

•
Warm off-white or light cream as the main background.

•
Muted gold or earthy orange as the accent color.

•
Light beige or sand as a supporting color.

Avoid:

•
Bright orange.

•
Harsh black as the main text color.

•
Too many colors.

•
Excessive gradients.

•
A generic medical blue-and-white visual identity.

Typography

•
Use a modern, highly readable Arabic web font such as Cairo, IBM Plex Sans Arabic, or Tajawal.

•
Use strong editorial headings with generous spacing.

•
Keep body text comfortable to read.

•
Preserve correct RTL behavior for Arabic and correct rendering of Latin terms such as Online, Offline, SEO, and Tima Med Tours.

Illustrations and imagery

Prefer custom SVG or CSS illustrations with one consistent line-art style.

Illustrations should be:

•
Minimal.

•
Modern.

•
Line-based or semi-line-based.

•
Limited in detail.

•
Distinctive but calm.

•
Directly related to the content.

Avoid stock photos, generic business handshake images, random laptop photos, generic medical imagery, clipart, and mixed icon styles.

Motion and Interaction

Keep the website alive but calm.

Allowed:

•
Subtle fade-in.

•
Gentle slide-in.

•
Simple card hover states.

•
Very light icon movement.

•
Smooth anchor scrolling.

Avoid:

•
Heavy parallax.

•
Heavy 3D effects.

•
Continuously moving text.

•
Spinning, jumping, or distracting elements.

•
Any animation that harms performance or readability.

Motion should support the content, not become the main attraction.

Layout and Spacing

•
Use generous white space between sections.

•
Do not fill every area of the viewport.

•
Give each section clear breathing room.

•
Use an organized grid with small compositional variations so the site does not feel like a generic template.

•
Use this visual rhythm:

Hero → Capability cards → Personal project → Experience evidence → Writing/research scene → Short introduction → Contact

The page should feel visually progressive while remaining easy to understand.

Responsive Requirements

Build Mobile First and ensure full responsiveness across mobile, tablet, and desktop.

Mobile

•
Keep the main headline strong and readable.

•
Stack the three capability cards in one column.

•
Scale illustrations down without losing meaning.

•
Make buttons easy to tap.

•
Do not make Arabic text too small.

•
Prevent visual crowding.

Desktop

•
Use generous horizontal spacing.

•
Allow a slightly asymmetrical grid where appropriate.

•
Use side space for illustrations.

•
Preserve clear RTL reading order.
